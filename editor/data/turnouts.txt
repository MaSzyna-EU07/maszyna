# The catalogue of the turnouts of the track editor (editor-tracks-domain.md §7): one type a line, the switch tool of the editor and
# the domain model of the track geometry (editor/layout) both read it. Built into the executable (CMakeLists.txt, editor_turnouts_txt.inc),
# so the game data doesn't need it. The templates the user makes in the switch designer are kept in eu07_switch_templates.txt in this
# same format, with their geometry given as parts.
#
# switch <name> <key> <value> ... source <the rest of the line>
#   name     in quotes, or with _ for a blank
#   type     Rz ordinary, Rls symmetric, Rpd double to both sides, Rpj double to one side, Rps symmetric double,
#            Rkp single slip, Rkpd double slip, Skrz diamond crossing
#   rail     60E1, 49E1, S42, - for none
# The geometry, of a type of the catalogue:
#   radius   m, of the curve of the diverging track; of the slip curves of a slip
#   ratio    n of 1:n at the end of the diverging track; of the two tracks parting of a symmetric switch; of the crossing of a slip
#   a        m, from the start of the switch to the crossing of the tangents (its centre); of a slip or a crossing from its centre to
#            the joints, the half length; none: the tangent of the curve
#   b        m, from the centre on along the main track; none: up to the end of the curve
#   diverging  m, from the centre along the diverging track where the scheme gives it another length than b
#   blades   tangent: the diverging track leaves the main one tangentially, its curve starting at the start or a pre-blade stretch
#            further where a is longer than the tangent; secant: the blades cut into the stock rails at 25' (S42), the pre-blade
#            stretch what a leaves of it, 0.6 m and the angle fitted to a where it leaves none
#   cut      m, the cut blade tip from the start of the curve (60E1, 49E1); none: where the blade gets 3 mm from the stock rail or
#            5 mm less 125 mm planed, about sqrt(2 R 0.005) - 0.125
#   fit      straights | transition | arc_straight_arc: the diverging track fitted to the tangents a and b (not of Id-4)
#   stagger  m, of a double switch: where its second switch starts along the main track
#   radius2 ratio2 a2 b2 diverging2 blades2 cut2   of the second switch of a double switch, as of the first one
#   middle   of a slip: 0 one arc for its slip curves, -1 a straight in their middle, the blades outside of the diamond
#   note     shown after the name on the list
# The geometry, of a template of the user: main, a, b, stagger, lead, entry (degrees), tip, lead2, entry2, tip2, heel, throw, and
#   parts <count> (<length> <R at the start> <R at the end>)..., parts2 ...: R 0 a straight, the same R at both ends an arc
# What the catalogue tells besides the geometry, - where it doesn't:
#   frog     fixed or movable (a movable nose)
#   locks    the number of the locks of the blades (Id-4 tab. 14-3)
#   drive    the family of the point machine
#   speed    km/h on the diverging track of the basic switch, ST-T1-A6 tab. 11.2 (by the radius, as switch_curve::basic_speed)
#   bending  m, the least radius of the main track of the switch bent one-sided, and the one allowed by way of exception,
#            ST-T1-A6 tab. 11.9; - where the table has no such basic switch
#   spacing  m, the least spacing of the tracks for a single crossover, ST-T1-A6 tab. 11.2; - where the table hasn't the type
#   source   where the values come from; what is unconfirmed is said so
